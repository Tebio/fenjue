## C. N字二波（金健米业类）——三次检验，最终证伪

走势解剖（600127 2026-08~09）：底横 → 8/6 放量首板(量比4.7) → 缩量回踩6日不破 → 8/18 二波放量涨停过顶 → 12日+109% → 9/2 天量剧震见顶。

**第一轮（二波启动日入场）**：1683 例，12 个入场×出场格**全部负期望**（最优 T_close+剧震离场 42.8%/-0.12%）。
**第二轮（回踩期 B+3 日缩量企稳入场，可执行口径）**：5589 例，事件研究口径全转正但极薄（+0.06~+0.68%）。
**第三轮（submit 六闸门+G7，next_open 口径）**：**REJECT**——G1-G4/G6/G7 全挂，全样本 T+5 43.8%/-0.01%，位置匹配边际 ≈0，资金曲线年化 -5.0%。唯一正格=恐慌期 52.5%/+1.0%（t=2.6 弱）。

**结论：金健米业类走势没有可交易的系统性 edge。** 「什么时候进」的诚实答案：
二波确认日进=稳定亏；回踩期进=账面微正但任何一道严口径下归零；它是幸存者偏差海报。
三连证伪（二波入场灭/回踩入场过不了闸/与打板族全灭互证）。阈值校准公开标注（量比 1.5、缩量 0.8 均为包含参照案例所调）。
检测器 `N字回踩企稳` 保留在 REGISTRY 作研究注记，不注册主张、不进影子盘。
