## 四、结论与用途定位

1. **「跟席位买」机械策略不成立**：可执行口径全部 ≤+0.2% 且胜率不过半，隔夜缺口收割了公告效应。
2. **基因库的真正用途 = 画像过滤器**：某票被格局型席位（章盟主/成都系/中山东路）净买入 → T5 衰减更慢，题材含金量高一档；被 T王/山东帮买 → 次日是出货窗口。这是**环境证据**，进打分卡不进买点。
3. **待过 submit 闸门的假设**（未测对照，别引用）：H1 机构净买入>T1_cc +0.60 是否存活于位置匹配对照；H2 格局型席位 T5 持续性（成都系/中山东路，n<300 需扩窗）；H3 席位×概念×市值的「章盟主高密度区」相似度评分。
4. 口径残留：席位名是 HiThink 标签（关联席位未合并）；窗口重叠非独立样本；hot_money_item_net_value 字段语义以 HiThink 官方为准；300/688 缺失。
