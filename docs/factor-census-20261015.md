# 公开因子矿普查 × regime 交叉（2026-10-15，过夜卡 t_9857628c）

> 一句话结论：**24 个公开因子 + 1 个引擎因子同场竞技，0 条达到自家「有效 α」标准**（三口径终审取最严）；
> 4 条过六闸门+G7 但 DSR 0.79~0.85 < 0.95 → 降级为**候选层**（进 backlog 影子观察，不进推送、不注册）；
> 家族级 BH-FDR 首次实战（#263⑧ 缺口）：25 次试探放行 11 个名义显著，其中 5 个是**预登记方向的反向显著**（=方向证伪）。

## 1. 选矿与设计纪律

从 GTJA191 / WorldQuant101 / qlib Alpha158 三库按 A 股逻辑精选 24 个日频因子（偏好量价结构/波动率不对称/资金流/拥挤度），
外加父卡 t_1dce09ff 的协同过滤引擎 GridCF OOS 打分作第 25 个因子。**跳过清单**（已在自家坟墓，不重测）：
MA 交叉族（#231 单指标全平/#241 四件套全平）、MACD/KDJ-K/RSI6/量比/ATR%（指标普查终审全平）、RSV（KDJ 同源）、
打板/封单（#257/#258）、分时/逐笔类（无 L2 数据）。

预登记（写在 `engine/factor_census.py` 文件头，先于任何数据观察）：
- 每个因子只测**一个做多尾**，方向由机制假设先验固定；
- 初筛三条件全过才送六闸门：T+5 尾-尾 ≥ +0.5pp 且 尾档日历 t_NW ≥ 2.0 且 十分档单调步 ≥ 6/9；
- 条件变体（×regime / ×簇）每因子至多 2 个，格内日级 t_NW ≥ 2.0 才送审；
- trials 分母如实报：stage1 家族 = 25，DSR 另按库累计 trials=7491 口径。

口径：信号日收盘可知 → 次日开盘入、一字开剔、净费 0.0015。初筛走矩阵口径（3335 票 × 1885 日全向量化，69 秒建成）；
**六闸门终审一律走 law_pipeline 原生扫描（权威口径）**，候选的 G 表数字以终审 JSON 为准。

### 家族级 FDR（BH, q=0.05, 家族=25）

BH 步进放行 11/25。其中**正向显著 6 个**：volcv20 / knn_vote / amihud20 / pv_corr_cv20 / ivol20 / pv_corr_ov10；
**反向显著 5 个**（预登记做多尾显著为负 = 方向证伪，比「平」更强的死亡证明）：gapfreq20(t=-3.00) / lshadow20(-2.83) / wq12(-2.43) / cntup20(-2.38) / ret5(-2.32)。

两个对照因子的行为验证了实验台不是回声机：
- **ret5（已知反转族标尺）**：无条件「每日买跌得最多的 10%」日历 t=-2.32 全 regime 为负——反转 edge 只在恐慌簇+极端深度里，每日机械买跌是负期望。与既有家族认知完全一致。
- **turn20（指标普查唯一活口的低换手梯度）**：T+5 日历 t=-0.62、T+20 t=+0.11 未复现——原梯度是月频/横截面口径，日频事件口径下不存在。
- **gapfreq20 = pooling 假象教科书**：池级尾-尾 +1.14pp 但日历 t=-3.00——十分档均值被高波动票的极端日绑架，日历时间口径当场戳穿。

## 5. 交叉项发现（本卡灵魂问题的答案）

- **「平时平、特定区域强势」的条件因子真实存在，但强度不够格**：量价相关性族（pv_corr_ov10/cv20/volcv20/amihud20）
  全样本本体过不了初筛 spread 门，**妖股期子集**却集体过六闸门（t_NW 15-16 事件级）。机制解读：妖股期无序小票行情里，
  「量价背离/量能稳定」筛出的是没被情绪资金蹂躏的票，均值回归土壤最干净。但 DSR 0.79-0.85 + 分年有负年（2021 全族负、
  ov10 的 2026 负）→ 只配候选层。
- **因子×簇交叉对十分档因子退化**：横截面十分档每天恒有 ~330 只尾档事件，「簇大小」恒 ≥30，簇维度无方差可言。
  簇状态交叉只对稀疏事件型信号（深档/跌停族）有意义——本次普查的簇变体全部按恒真退化剔除，不计 trials。
- **knn_vote 的四 regime 全正**（妖股 +0.40pp/t3.2、平淡 +0.20/t2.6、主线 +0.51、恐慌 +0.40，OOS 日数 64~435）
  且 OOS 四年全正——引擎打分是本次普查里**唯一跨 regime 不翻脸的连续定价面**，强化 #276 的排序层定位（RES-07）。
- **主线期条件变体整体弱**：dvol_ratio20@主线期 G2 挂（2019-22 主线段零超额）；主线期是妖股期条件族的镜像弱区。
