# START HERE（接手 AI / 人的唯一入口，5 分钟定向）

> 你（未来的 AI 或人）**不要**先通读 `AGENTS.md`——那是 400+ 行的历史台账，通读会烧掉你的上下文且无用。
> 按下面的顺序读，读够就开工。

---

## 0. 三句话理解这个仓库

1. 这是**一个人**的 A 股量化研究+生产系统（不是机构）：所有结论都在 `AGENTS.md` 台账里编号存档（**只增不改**）。
2. 面向未来的工作全部在 `docs/plan/`：**任务队列**在 `backlog.yaml`，**每个任务的契约**在 `specs/`。
3. 你的目标不是"多写代码"，是**把研究结论变成可验证的生产闭环**，同时**不给系统增加熵**。

## 1. 读什么（按顺序，读够即止）

| 顺序 | 文件 | 目的 | 读完你应该知道 |
|---|---|---|---|
| 1 | 本文件 | 定向 | 规矩、权限、当前阶段 |
| 2 | `CONSTRAINTS.md` | **硬约束（最重要）** | 哪些事**绝对不许做**（禁复活清单/权限边界） |
| 3 | `DECISIONS.md` | 已冻结决策 | 哪些设计**不许重新讨论**、什么条件下才可翻案 |
| 4 | `INTERFACES.md` | 冻结的数据契约 | 文件路径/字段/单位/精度（**改它=改全系统**） |
| 5 | `backlog.yaml` → 你那条任务 | 任务详情 | acceptance / depends_on / gate |
| 6 | `specs/<你的任务>.md` | 实施契约 | 输入/输出/接口 demo/验收正反例/回滚 |
| 7 | 需要时按编号查 `AGENTS.md` | 历史证据 | 那条结论的原始证据与判决（**不要通读**） |

`README.md`（总纲：三层模型、节奏日历、路线图）与 `module-layout.md`（目标代码树、依赖规则）**按需**查，不必先读。
`mindmap.md` 只在你要确认"某功能归谁/放哪"时看。

## 2. 三条铁律（违反即返工）

1. **先有 spec 才许开工**：`backlog.yaml` 里 P0/P1 条目若无对应 `specs/<id>*.md` → 你的第一件事是**写 spec**（用 `specs/_TEMPLATE.md`），不是写代码。
2. **依赖只许向下**：`core/` 不许 import 上层；`lines/` 之间不许互相 import；**费用与税费只能来自 `taxfee/`**（禁止新出现 `0.15` 这类字面量）。
3. **验证必须拿真实输出**：跑 `scripts/verify.sh` 与你的 spec 里的验收命令；不许"我觉得对了"。没有输出的完成＝未完成。

## 4. 权限边界（谁能决定什么）

| 可以自己决定（不用问） | **必须先问用户** |
|---|---|
| 实现细节、命名、测试写法、注释 | 改任何**已注册线**的规则/参数（走 DECISIONS D-变更流程） |
| 新增单测/断言/golden 用例 | 动**资金/仓位/下单**相关默认值 |
| 修 docstring、补类型、重构等价代码 | 删除/覆盖任何 `data/` 下的历史产物 |
| 新建 `engine/<pkg>/` 下暂未被生产调用的模块 | 改变**公开/私有**面（仓库可见性、发布内容） |
| 加日志、加断言、把硬编码抽成常量 | 引入新**外部依赖**（库/服务/付费数据源） |
| 优化跑批时间（不改变输出） | 变更 cron **排程时刻**或**推送行为**（会打扰人） |

## 5. "直接开干"的七个坑（前人踩过，别再踩）

1. 改 `AGENTS.md` 已有条目（它是免翻案的历史，只能追加新编号）。
2. 在 `lines/` 里写第二套成本计算（→ 全系统口径再次分裂，见 #262-C）。
3. 用前复权价做"低价/高价"这类**价格标签**（→ #265③ 已经错了一次，6.8% 误标）。
4. 复活已被证伪的规则（技术过滤/动量突破/打板/缠论…，见 `CONSTRAINTS.md` C1）。
5. 拿事件研究的均值当实盘期望（→ #249 教训：事件 +4~7% → 组合 +1.15%）。
6. 只跑 `py_compile` 就宣布完成（→ 必须真实入口实跑 + 验收命令）。
7. 把新结论只写在聊天/注释里，不落 `AGENTS.md` 编号 + `backlog.yaml` status（→ 下次没人知道做过）。
