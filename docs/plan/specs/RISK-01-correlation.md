# SPEC · RISK-01 多线相关性实测与"分散幻觉"检验（P1，1.5 天）

## 目标
回答一个当前**完全没有数字答案**的问题：**这四条线一起上，风险是分散的还是叠加的？**

## 非目标
- 不做因子风险模型（Barra 式）——已列入 not_doing
- 不做组合优化求解——只做"测量 + 限额"

## 现状证据
- `corrcoef` / `corr_matrix` / `cov_matrix` / "协方差" 全仓库 **零命中**（#263①）
- 四条线**全是 A 股多头 + 低位/逆向**：#241 预增池（低位小市值漂移）、#254 深档（恐慌抄底）、#250 金股（小市值注意力）、#242 调样抢跑（被动盘）
- 直觉判断（待验证）：**分散幻觉**——所谓"日历互补"是时间错开，不是风险分散；恐慌日深档线触发时，恰是其他线最难受的日子（#265⑩）

## 输入
- `PORT-01` 输出的各线日收益序列（`nav_series()` + `contributions()`）
- 指数序列：`data/index_sh000001.json`（大盘）+ 小市值代理（可用 `data/cap_hist/` 构小市值等权指数）

## 验收（正反例）
- 正例：输出 4×4 相关矩阵（全期）+ rolling 60 日曲线数据 + 与大盘/小市值的相关
- 正例：`verdict()` 给出**明确判断**（分散幻觉 真/假）并附数字依据（均值相关、最大相关对、重叠度）
- 正例：与手算样例核对（用 20 个交易日的假数据验证 `corr_matrix` 正确）
- 反例：某线全期只有 15 个簇日（深档）→ 相关性样本极少，**必须标注置信度/有效样本数**，不得给"看起来精确"的数字
- 反例：把空仓日当 0 收益参与相关计算 → 会严重高估分散（空仓 0 收益与市场无关）→ 实现必须**同时给出"仅暴露日"与"含空仓日"两套**，并在结论里说明差异

## 风险
- 小样本线（深档 63 笔/15 簇）相关性不可靠 → 只能给区间，不能给点估计
- 相关性在极端期会跳升（危机时趋于 1）→ 必须**单独看极端窗口**（配合 RISK-03 压力测试）
