## C2 统计纪律（防"看起来显著"）

1. **防前视**：信号只能使用 T-1 及更早的信息；回测入场一律下一交易日（#8、#9、`backtest_no_future.py`）。
2. **重叠事件**必须用 Newey-West HAC（lag=持有期）**且**做日历时间组合（#263-A）；单一 t 值不算证据。
3. **样本量门槛**：小样本线（深档 63 笔/15 簇、调样 n=569、下修 n=155）必须标注**功效/置信区间**，不得直接宣称胜率（#263②）。
4. **DSR 的 trials 必须登记**：没有登记的试探会让 DSR 分母偏小 → 显著性虚高（#265⑦）。
5. **双段复验 ≠ 样本外**：`2019-22/2023-26` 已被多条线重复使用，第二段已污染（#265⑥）→ 新结论必须走 holdout（RES-01）。
6. **事件研究均值 ≠ 实盘期望**：组合级翻译（逐笔现金守恒）才算期望（#249：事件 +4~7% → 组合 +1.15%）。
7. **位置匹配对照**：任何"低位/高位"主张必须给同票近邻或同日随机对照（#260 方法论）。

## C3 数据纪律

1. **价格标签用不复权价**（"<5元/低价层/高价"一律 `big_kcache_unadj`）；前复权只能用于收益序列（#265③）。
2. **收益序列用前复权**，且**不得跨复权锚拼接**（分红后整体变化，靠哨兵校验，见 #261 的 SEAM-FIX）。
3. 退市股不在 `big_kcache` → 所有低位小市值结论存在**方向已知（高估）**的偏差，引用时必须声明（#265⑤、#262-B）。
4. **一字板/停牌一律剔除**（不可成交）并记录剔除数量（#15、#254）。
5. **交易日历走官方**（`query_trade_dates`）或用指数文件，但**禁止把增量产物的尾部日期当作"今天"**（#263 时序坑）。
6. 读旧 JSON 用 `utf-8-sig`（BOM 陷阱）；写新文件不带 BOM。

## C4 交易与成本纪律

1. **不用杠杆、不做空、不对冲自己的 beta**（DECISIONS D-06）。
2. **所有费用与税费只能来自 `engine/costs.py`**；`lines/`、`portfolio/` 里出现 `0.15` 这类字面量＝bug（#263④）。
3. 执行假设固定写死并声明：**9:25 竞价挂单 / 次日开盘买入**（#241b：等盘中低点＝自动筛掉强者）。
4. 滑点不做理论建模，**用对账实测回填**（#263⑦、MID-01）。
5. 容量约束用 ADV 与容量曲线说话，不用"感觉"（#250、PORT-03）。

## C5 变更与复杂度纪律

1. 改 **LIVE 线**规则：提案 → 样本外/holdout 验证 → 台账新编号 → registry 版本号（GOV-03）。
2. **新增一条线必须先退役一条**（或给出机械失效判据）；**cron 总数不增**（新增必合并）（README §7.5、OPT-02）。
3. 单模块 ≤ 400 行；超过即拆分（`stacking-guard` 纪律）。
4. 迁移旧脚本时**必须双跑对照**，差异 > 0.1pp 必须解释并记录（PLAT-05）。

## C6 架构禁令

1. 不许出现第二套成本口径 / 第二套收益口径（这是 #262-C 的病根）。
2. `core/` 不许 import 上层；`lines/` 之间不许互相 import（`module-layout.md` §2）。
3. **账本只记账，不装业务规则**（排序/止损/择时留在 `lines/`）。
4. 不许整仓迁 Qlib/QuantConnect/聚宽/米筐（D-04）；不许引入付费终端/数据源（D-12）。
5. 不许把新结论只写在聊天、注释或临时脚本里：**必须落 `AGENTS.md` 编号 + `backlog.yaml` status**。
6. 不许改 `AGENTS.md` 已有条目（历史免翻案，只能追加）。

## C7 安全与资产纪律

1. 持仓/资金/台账/对账/凭证一律**不进公开仓库**（`INTERFACES.md I7`、SEC-01）。
2. 凭证只走本地加密存储与 stdin 传递，**不进聊天、不进 argv**。
3. 删除 `data/` 历史产物、改变仓库可见性、发布任何对外内容 → **必须先问用户**。
