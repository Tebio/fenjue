# 焚诀作战手册 · 2026-09 起（v1）

> 每条规则后面是证据编号（AGENTS.md #xx）。这不是建议清单，是实测过的纪律。
> 所有数字净口径（扣 0.15%）。研究辅助，不是买卖指令。

## 仓位结构

| 层 | 占比 | 内容 |
|---|---|---|
| 底仓 | 60-70% | 红利躺平（五大行级，连续≥3年分红，息率≥4.5%买入线） |
| 进攻仓 | 0-30% | 反人群打板（规则见下） |
| 侦察仓 | 0-10% | 观察池临启动票的半路板（回测立项中，未验证前不上真钱） |

## 底仓规则（红利线）

- 买点：时点 TTM 息率 ≥4.5%（银行委托单每天 16:05 推 QQ，照抄挂单）
- 卖点：息率 <3.5% 减卫星仓；核心仓不清（轮动清仓版实测跑输躺平 13pp，#60）
- 分红税纪律：持仓满 1 年免税——买入区躺好跨分红季，别在除息日前抢权（#59）
- 证据：8 年 +103.9%~+116.7%，八年每年全正，2022-24 熊市上证 -46.5% 时五大行 +48.4%（#59/#60）

## 进攻仓规则（反人群打板）

- **只在平淡期/恐慌期开仓**（2026 实测：主线/妖股期开缝是坑 -2.6~-2.9%，平淡 +1.28%/恐慌 +2.53%，#56）——面板周期仪徽章是油门：热闹的日子忍住，恐慌的日子出击
- 入场：观察池临启动票（入池 1-5 天，中位 2 天毕业）+ 盘中冲板 + 板块梯队≥3 + 市值 20-400 亿 → 挂涨停价排队，尾盘开缝才成交，封死板放弃（#41/#46/#53）
- **出场=断板即跑**：没涨停→尾盘 14:50 卖；又涨停→隔夜次日早盘 9:30 卖。禁止"情绪逻辑没破再拿两天"（动态宽容实测 -15.3%，宽容期=流血期，#61）
- 禁止"主线期全仓打主线"（闸门实测 -48pp，主线期排队最卷，#62）
- 仓位：单票 = 可用现金 1/3，仓满自动放弃新信号，日≤3 笔
