## 二、A股本土实证（券商研报+全量统计，非水文）

1. **广发证券《交易策论·情绪周期与赚钱效应》(2025-08，Wind 数据)**：连板晋级率频率分布（2023-2024）——1进2 晋级率天然低（量化打板套利盘压制），低位板（1-3板）晋级失败回撤有限，高位板（7+）极端亏损 -20%+；晋级率是 A股 T+1+涨跌停制度的特色指标，中期分布稳定。
2. **百果量化全量首板统计（2024-01~2025-01，25,019 样本）**：总体炸板率 35.9%；**反常识：尾盘 14-15 点封板的次日溢价 +0.91%/成功率 50.6% 最高，9:30-10:00 早盘板 -0.75%/44.3% 最差**——与"大佬都说别打尾盘板"的经验相反。
3. **头条实测（2024 全量非一字板 2,376 次）**：无脑打板次日 -0.3%/41%；筛选「10:30 前封板+封单/流通>2%+换手 5-10%」后到 55-60%。（注：与百果的封板时段结论矛盾——时段因子不稳定，两个来源打架本身就说明它不可靠）
4. **学术正典见《持仓处置研究》§六**（海龟/幽灵/Odean/Feng&Seasholes 中国版/Han-Zhou-Zhu）。

## 三、结论：没有圣杯单策略，完整体系是分层的

联赛证明：**无差别全市场口径下，绝大多数流传策略 ≈ 随机或更差**。赚钱的不是某个形态，是"什么时候用哪个"：

```
第 0 层 压舱石（永续）：高股息锚买入区挂单（样本外两段双赢 +1.1pp）
第 1 层 统计套利（每日）：反转族 跌3%→次日开盘（+0.14~0.16%，靠分散）
        + 跌停次日接（+1.06%/54%，待流动性修正复核——最强候选）
第 2 层 周期闸门（何时放大/收缩）：主线期尾盘买强票 +0.47%；
        妖股/退潮期收缩——反转族两日连亏 -1.15%/-1.65% 就是没闸门的代价
第 3 层 持仓处置（已实测）：大跌三分法/涨停隔夜兑现/假突破走/回本不操作
第 -1 层 黑名单（同样值钱）：打板无差别挤进、首板次日追、海龟突破、
        MA20上穿、三连阴、缠论B1、止盈2%——每少踩一个坑都是钱
```
