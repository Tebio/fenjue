# 回测框架对标：Backtrader / VectorBT / 自家引擎

*成文 2026-10-15（kanban t_02c4b3b5）。所有「自家」数字均为本次实测或引自 `AGENTS.md` 台账编号，未引用的推测已标「假设」。*

---

## 0. 一句话结论

**比错了对象。** Backtrader / VectorBT 是「执行引擎」（给你一根 bar，问你买不买）；自家 `law_pipeline` 是「证伪引擎」（给你一条主张，问它该不该死）。二者不是同类件，谈不上谁优谁劣；真正缺的不是回测器的速度，而是**从研究台到账户的最后三公里**（组合账本 / 执行成本真实化 / 实盘对账 / 可复现锚）。

对自家而言，Backtrader 能补的只有一项（逐 bar 的成交语义），VectorBT 能补的只有一项（参数扫描速度）——两项都不是当前瓶颈；而两者的**数据层、PIT 纪律、容量模拟、多重检验、状态机全部要重造**，换过来是净亏。

### 1.1 为什么自家框架长成这样（真实实证，非设计偏好）

它不是为了「替代 backtrader」长出来的，是被三次事故逼出来的：

1. **`G7 容量闸门` 的诞生**——事件研究口径下，跌停/深跌族全信号均笔 **+4.58%**、看着极漂亮；套上 10 槽资金约束后**实际成交子集只有 +0.02%**，而未成交子集 +5.38%。**资金有限时你结构性买到的是平时零星日子的信号**（成簇恐慌日的好票根本轮不到你）。Backtrader 会照跑这 10 槽给你一个正的权益曲线、什么都不说；自家管线把这条写成了第七道闸门（`references/capacity-simulation.md`）。
2. **`pick` 规则的方向陷阱**——同一族信号，槽位「先到先得」分配把 **+4.58%/笔 压成 -0.75%/笔**，凭空造出「策略无效」的假结论；改用随机选票 + 多规则交叉后结论才稳定。这是「回测器语义」层面的坑，任何引擎都不会提醒你。
3. **口径漂移的代价**——一次复测漏掉「低位过滤」条件，同一策略跑出 **-184%**（#253）；暴露的是「同一逻辑两处实现」的结构性问题，不是引擎问题。

**这就是为什么自家框架的第一性原则是「防伪」而不是「仿真」**：对个人量化，最大的亏损来源不是滑点没建模，是把 β 当成 α、把样本内当样本外、把吃不到的信号当利润。

### 2.4 G7 容量闸门：注册表的整体体检（本次实测）

`data/claims_registry.yaml` 本次实测 **67 条主张**，其中 **53 条带 `g7_槽10` 字段**：

- `过G7 = true`：**41 / 53**（77%）
- `过G7_K5 = true`：**10 / 53**（19%）
- 带 K1 数值明细的 37 条中，**K1 年化 > 0 的 25 条**（68%）

⚠️ **口径警告（须在引用这些数字时同时声明）**：`过G7=true` 有 **16 条只有 `{"过G7": true}` 而没有 K1 数值明细**（全部是 `CROSS_LOW_*` 交叉族）——与 `capacity_audit.py` 产物 `data/capacity_audit_20260918.jsonl`（19 行）**对不上**。判定：`g7_槽10.过G7` 这一位在不同批次里由不同脚本写入，**布尔位已被污染，不能当「已过容量闸」的可靠凭证**；引用时以带 K1/K5 数值的 37 条为准。这是一条新发现的**记账缺陷**（不是策略缺陷），已写入本文件供后续清理。

**活下来的与挂掉的**（与 `references/capacity-simulation.md` 的结论一致，本次实测复核）：

- 挂掉的是清一色 **β 型**（K1 年化深度为负）：`PANIC_DEPTH_DOSE -26.2%`、`LIMITDOWN_NEXT_DAY -26.23%`、`FRONTRUN_FIRSTBOARD_V2 -26.53%`、`REVERSAL_OPEN_T1 -23.43%`、`WATCHPOOL_GRAD -20.97%`、`HIGH_UPPER_DISTRIBUTION -20.37%`、`LIMITDOWN_LOW_MA60 -18.3%`——**它们的钱全集中在成簇恐慌日**。
- 活下来的是 **「信号稀疏 + 条件极端」**：`COMP_LIMITDOWN_LOW_DEEP +11.93%/年`（最高）、`COMP_LIMITDOWN_LOW_LOSER250_OS20 +11.37%`、`COMP_LIMITDOWN_LOW_3DOWN_DEEP +9.97%`……

**这道闸门是自家框架对 Backtrader/VectorBT 最不可替代的一处**：两个开源引擎都没有、也不会给你「均笔 +4.58% 实际只能吃到 +0.02%」这个数字。

## 4. 一句话总结

自家框架在「**推断纪律**」上已经超过大多数个人量化（HAC t 值、日历时间组合法、DSR、防前视断言、容量闸门、分年验尸、位置匹配对照、证伪台账），真正的大洞是「**组合/风险层原料为零 + 执行成本两套口径 + 实盘对账断链 + 无 holdout/无版本锚**」。**Backtrader 和 VectorBT 一个都补不了这些**——它们解决的是「怎么把策略跑出来」，而当前的问题恰恰是「跑出来的数字能不能信、能不能真的拿到」。差的不是聪明，是**从研究台到账户的最后三公里**。
