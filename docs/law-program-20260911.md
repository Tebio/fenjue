## 一、什么配叫「定律」（毕业标准，五条缺一不可）

一条规律要升格为定律（Law），必须同时满足：

| # | 标准 | 检验方法 | 现有结论对号入座 |
|---|------|---------|----------------|
| L1 | **有机制解释**——说清钱从谁口袋来、为什么持续 | 写出"谁在亏钱给我"的传导链；写不出 = 只是数据挖掘 | 高股息（企业盈利分配）✅；反转族（恐慌过度定价）✅；低位避雷针（主力试盘）⚠️机制弱 |
| L2 | **跨 regime 稳健**——主线期/妖股期/恐慌期/平淡期分段都活着 | regime_timeline_hcap 切四段各测 | 反转族✅（双段）；多数信号未做❌ |
| L3 | **跨宇宙稳健**——主板/创业板/小市值/大市值不翻车 | 分市值五分位×分段 | 全部未做❌ |
| L4 | **成本+容量后可交易**——净 edge > 3×费用，容量够实盘仓位 | 净口径 + 冲击成本估算 + 年触发频次×单笔 edge = 年化贡献 | 反转族 +0.16%/T+1 勉强✅；形态族单笔+0.8pp但低频❌（单独不成策略） |
| L5 | **前向实盘确认**——影子盘跑 ≥20 个交易日不衰减 | stock_shadow_record 式前向记录，edge 半衰期监测 | 全部未做❌（影子系统只测了焚诀 V2 追高门） |

**当前体系里没有任何一条定律。** 最高级别的是「双段复验成立的统计规律」（L1+L2），离毕业还差 L3/L4/L5。蓝图里所有 ✅ 标记改读为"候选规律"，不是定律。

## 二、目标架构（四层，先设计后实现）

```
L4 定律层     ← 五条全过的规律（当前为空，这是长期目标）
L3 组合层     ← 规律之间的权重/叠加/互斥规则（当前未测，最大空洞）
L2 信号层     ← 候选规律库，每条带证据等级标签（当前主要产出地）
L1 数据底座   ← 日K✅ / 分钟线❌（最大硬欠账）/ 盘口封单❌ / 业绩预告事件库❌
L0 证伪管线   ← 随机对照+分段+分宇宙+成本压力+影子前向（五件套自动化）
```

**空洞排序**（决定迭代优先级）：
1. **L1 分钟线数据库**——盘中择时类规律（大佬买回踩那种 edge）全部不可测，这是物理瓶颈
2. **L3 组合层**——形态×位置、反转族、股息锚之间的权重完全没测
3. **L0 自动化**——五件套现在是手工跑，必须固化成一键管线，否则每次研究都重新发明轮子
4. **L2 信号库扩充**——PEAD 事件库（业绩预告超预期，外部最强新方向）

## 三、迭代机制（长期节奏）

**每周一个研究冲刺**，每冲回答一个可证伪的问题，产出物固定四件：

1. 实验脚本（engine/，确定性可复现）
2. 原始数据（data/*.json，供抽查）
3. 分段/分宇宙/对照组三件套结果
4. 入库判决：候选升级 / 维持 / 降级 / 证伪（写进蓝图+AGENTS.md 台账）

**冲刺队列**（按序，每周末清算本周进度）：

| # | 冲刺 | 核心问题 | 预计 |
|---|------|---------|------|
| S1 | 证伪管线固化 | 五件套一键化，后续所有研究零边际成本 | 1周 |
| S2 | 分钟线数据库立项 | 数据源选型（akshare/baostock分钟级/券商L2）、存储、回填8年 | 2-3周 |
| S3 | 组合层首测 | 反转族×形态×位置的最简权重（加法式 vs 投票式 vs 闸门式） | 1-2周 |
| S4 | PEAD 事件库 | 业绩预告抓取→SUE计算→T+N衰减曲线，趁因子未死趁早 | 2周 |
| S5 | 定律影子盘 | 候选规律全部挂上影子前向记录，攒20交易日样本 | 持续 |

## 四、算力分工（用户 2026-09-11 指定）

- **策略判断/机制推理/证伪设计 → K3（本模型）**。机制解释（L1）和证伪实验设计是智力活，不外放。
- **高频执行层 → DeepSeek V4.1 flash**：批量初筛（候选池粗筛、文献摘要初读、数据清洗脚本生成）、大批量机械验证（分宇宙×分段的矩阵式重跑）。它出初稿，K3 审判决。其自荐营销数字不采信，只当劳动力。
- **营销数字/胜率声明一律以自家数据为准**，任何模型的自我报告都不作证据。

## 五、纪律条款（防再犯）

1. **禁止打地鼠**：用户随口点一个形态/战法，不再当场测完就甩结论。点名的进冲刺队列排期，按管线走。
2. **禁止单独报道单次回测**：没有随机对照+分段复验的数字，回复里只能标"未验证直觉"，不得进蓝图。
3. **蓝图用语降级**："定律级发现"等词禁用，统一改为证据等级标签（候选L1L2 / 待L3L4L5）。
4. **每周清算**：周末向用户报告本周冲刺进度+判决，不是攒一堆再说。

## 六、自我修正回路 + Token 经济学（2026-09-11 终夜增补，对齐大厂方法论）

参照系：WorldQuant BRAIN（alpha 提交全自动确定性闸门，零人工）+ Google ML Test Score（生产就绪清单）+ SRE 监控哲学（告警必须可行动）。

### 四层找洞机制（按成本排序，能用下层就不用上层）

| 层 | 机制 | 成本 | 职责 |
|---|---|---|---|
| **L0 提交闸门** | `law_pipeline.py submit <信号>`：六道硬闸门（t_NW≥Harvey3.0 / 双时间分段 / regime≥3/4 / 市值≥4/5 / 位置匹配边际>0 / 0.30%成本仍正），CI 式 exit code，REJECT 即拒收 | **零 token** | 新信号入库前全检——找洞是代码的事 |
| **L1 持续审计** | `claims_audit.py` 周审计 cron：滚动250日边际贡献 vs kill线，状态机自动降级，看门狗只报变更 | **零 token（纯 Python），cron 汇报走常规模型** | 已入库主张的存活监控——结论死了系统自己发现 |
| **L2 DeepSeek V4.1 flash** | 攒批制：文献初读摘要、对抗假设批量生成（"给我20个可能推翻X的机制解释"），每周最多一批，预算封顶 | 每周一次批量，非每次找洞 | 产生候选假设（假设本身不值钱，验证才值钱） |
| **L3 K3** | 只裁决 L0/L1 判不了的模糊案 + 机制推理 + 证伪实验设计 | 最贵，最少用 | 智力活，不做机械活 |

**Token 最优解的核心洞察**：找洞 90% 是统计检验（确定性代码），9% 是批量机械判断（flash 攒批），只有 1% 需要贵模型。DeepSeek 的角色是"假设发电机"——它一次生成 20 个候选证伪角度，我全交给 L0 管线跑，token 花在产生假设上，不花在验证上（验证是免费的）。
