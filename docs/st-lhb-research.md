# A股「ST摘帽/重组」与「游资龙虎榜」玩法证据链调研

## 一、制度事实(可核实)

**1. *ST vs ST(制度定义)**
- *ST = 退市风险警示(财务类/交易类/重大违法类/规范类触发);ST = 其他风险警示(资金占用、违规担保、分红不达标等),风险等级低于*ST。*ST须先"摘星"才可能"脱帽",分两步走。
- 涨跌幅:2026年7月6日起,沪深主板ST/*ST涨跌幅由±5%放宽至±10%,与主板普通股一致;创业板/科创板ST股为±20%,北交所±30%(来源:沪深交易所公告,澎湃新闻/央视网2026-07报道)。异常波动披露阈值同步由±12%调至±20%。
- 买入ST需签《风险揭示书》,单日买入单只ST上限50万股。

**2. 壳资源价值变迁(2020后)**
- 借壳上市数量:2016年34家 → 2021-2025年年均仅2-5家(雪球专栏引述,待一手核实);2023年首次披露借壳仅3起,较2022年4家继续萎缩(21世纪经济报道,引新"国九条"报道)。
- 政策端:2024年4月新"国九条"+证监会《关于严格执行退市制度的意见》明确"削减壳资源价值"、严打保壳;主板营收退市门槛提至3亿元、市值退市标准由3亿提至5亿。
- 结论方向明确:2020年后壳不再值钱的"卖壳逻辑",仅"产业整合平台"价值残留;但"借壳案例同比-63%"等具体数字仅见于自媒体专栏,无券商研报一手出处。

## 二、收益统计(证据强度低,均需打折)

**3. 摘帽行情**
- 自媒体汇总(同花顺社区,iFinD数据):2022年48家摘帽,首日涨停占比29%,首日上涨概率约47%;2023年10只摘帽4涨6跌;2022-2025四年首日上涨概率约45%-50%,约30%个股首日跌超5%。结论:摘帽首日大涨并非必然,"利好出尽"常见。
- 网传"2018-2022摘帽前30天均值+15.6%、当天+3.2%、后60天+12.1%"(CSDN个人博客,样本口径不明);"2026年摘帽策略胜率38%、摘帽后一月平均跌18.7%"(券商投顾营销问答,无出处)。**均未找到广发/海通/东吴等券商摘帽专题研报原文,以上数字只能作方向参考,不可当实证。**

**4. 龙虎榜席位跟随**
- 唯一成规模的公开回测为个人量化研究(CSDN,2023-2025年28.7万条上榜记录):知名游资席位上榜后未来5日平均超额收益**-1.2%**、跑赢基准概率仅41%——"跟知名游资买"是反向指标;机构席位+1.7%(54%)、新进私募席位+3.7%为正向。非券商研报,方法论未经同行评审,但方向与"游资席位已被充分定价"的常识一致。**未找到券商对席位跟随策略的正式实证。**

**5. 退市风险(ST股"死亡率")**
- 退市数量:2022年41家、2023年44家、2024年52家(历史新高,Wind/证监会口径)、2025年29-32家(两来源不一致)、2026年前9个月约27家(证监会李超:2024年以来累计108家)。
- 2024年152家公司披星戴帽,同比+29.9%(Wind,截至2024-12-18);2025年面值退市6家、市值退市4家,重大违法退市创新高。**含义:押注ST本质是在一个年退市率持续抬升的池子里博小概率摘帽,赔率结构已系统性恶化。**

## 三、5%→10%对策略的影响(制度事实+推断)
涨跌幅放宽后:封板资金成本翻倍、连板套利空间压缩;利空日单日亏损上限翻倍,加速劣质标的跌向面值/市值退市线。交易所公开表态目的即"减少过度炒作、提升定价效率"。

**总体判断:摘帽/壳/跟席位三类传统玩法,制度端(退市新规+放宽涨跌幅)与统计端(胜率、超额收益)证据一致指向策略环境恶化;但高质量券商实证缺失,散户能拿到的数字多为自媒体口径。**
