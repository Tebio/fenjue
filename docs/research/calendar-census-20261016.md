# 日历普查：玄学/日历效应（天干地支的严肃化版）——全灭销案

## 0. 一句话结论

**「玄学选票」在严肃化之后是 0/14 存活——月相、节气、农历初一/十五、星期、月初月末
全部过不了预登记三闸。** 唯一在形态上接近文献结论的是 turn-of-month（TOM），
但它挂在 Harvey 3.0 与近两年口径上，且「有毒年」恰好是最近一年——**按项目一贯纪律不给例外**。
本报告即交付物（用户好奇心驱动，成本 2 小时级，证伪亦交付）。

## 1. 方法（预登记，跑前写死）

宇宙 = 主板 big_kcache 全量 **3335 只**，2019-01-02 → 2026-10-15（**1886 交易日**）。
日收益 = 全宇宙等权 `close/close-1`（|r|>21% 判脏数据剔除；当日覆盖 <500 只剔除，
实测有效 **1885 天**、中位覆盖 **3157 只**）。
交易日历锚定 000001（活跃参照股，禁 union 全宇宙尾部）。

| 家族 | 窗口定义 | 窗口交易日数 |
|---|---|---|
| moon_full | 天文**望**（BJT 日）±2 自然日内的交易日 | 322 |
| moon_new | 天文**朔**（BJT 日）±2 自然日内的交易日 | 307 |
| term5 | 24 节气各自锚定「节气日后首个交易日」起连续 5 个交易日（T+1..T+5） | 936 |
| lunar_1 | 农历初一（=天文朔 BJT 日）当日或之后首个交易日 | 98 |
| lunar_15 | 农历十五（=初一+14）当日或之后首个交易日 | 97 |
| lunar_both | 初一 ∪ 十五 | 194 |
| tom | 每月最后 1 个交易日 + 次月前 3 个交易日（McConnell-Xu 口径） | 373 |
| tom_end / tom_start | 仅月末 1 日 / 仅月前 3 日 | 94 / 282 |
| weekday_0..4 | 周一~周五（每桶 vs 其余） | 各 ~370-383 |

**统计量** = 窗口日均收益 − 非窗口日均收益（市场级；日历效应本身就是 beta 层问题）。
**推断** = 双侧 Newey-West t（lag=10，两组各算长程方差）+ **1000 次结构保持置换检验**：
moon/lunar/term/tom 按**自然日**抽样同数量伪锚并走同一条「日期→交易日窗」映射
（因为真实相位/节气本来就落在任意自然日上）；weekday 用 **ISO 周内星期标签洗牌**
（保持周内自相关与假期结构）。`p2 = (1 + #{|placebo| ≥ |real|}) / (1 + N)`。
**三口径**（禁裸均值，每口径报 NW t）：FULL 全段 / FRONT 2019-01→2022-12 / RECENT 2024-10-16→2026-10-15。

**存活判据（预登记）**：① FULL |t_NW| ≥ 3.0（Harvey 门槛，本批正式假设数 = 14）
② FRONT 与 RECENT 两口径**同号** ③ 置换 p2 ≤ 0.05。全过才进六闸门终审。

### 天文层自证（零依赖手算，无 lunardate/sxtwl/ephem）

节气 = 视太阳黄经过 15° 整数倍（低精度公式）；朔望 = Meeus 低精度（主项+14 修正项）。
**22/22 校验锚全中（节气 16/16 精确到日、朔望 6/6 精确到日）**：
立春 2024-02-04 / 2026-02-04、清明 2024-04-04、冬至 2024-12-21 / 2025-12-21、
大寒 2025-01-20 / 2026-01-20、朔 2024-02-10 / 2025-01-29 / 2026-02-17（三年春节）、
望 2024-09-18（中秋）/ 2025-02-12 / 2026-03-03（元宵）。

### 2.1 最有数学意义的负结果：节气

- **聚合无信号**：24 个节气后 5 日窗口合并 FULL diff = −1.28bp、t=−0.20、p2=0.86——**完全在噪声里**。
- **逐节气分散且无法用样本量救**（每个节气 8 年只有 8 个样本，属描述性统计，非证据）：

| 节气 | 窗口日均−全样本 (bp) | 8 年胜率 |
|---|---|---|
| 雨水 | +71.3 | 88% |
| 立春 | +55.0 | 88% |
| 立夏 | +25.8 | 75% |
| 立冬 | +21.4 | 86% |
| … | … | … |
| 清明 | −17.8 | 25% |
| 小满 | −20.0 | 38% |
| 秋分 | −31.3 | 12% |
| 大寒 | −42.5 | 38% |

「立春/雨水好、谷雨/秋分差」看起来诱人，但 **n=8**；这正好演示了为什么预登记门槛必须卡死——
24 个格子里挑最好的两个，等于做了 24 次检验（24 × 5% ≈ 1.2 个假阳预期），没有任何可用 edge。

### 2.2 最接近文献的 TOM：为什么仍然不给例外

TOM 是 A 股/美股文献里被反复验证的方向（McConnell & Xu 2008 等），本普查也确实读出了
同方向的正超额（+22bp/日、NW t=2.36、置换 p=0.011——**置换检验过了**）。
按「金格必须过分年验尸」纪律拆开：

| 年 | tom diff (bp/日) | tom_start diff |
|---|---|---|
| 2019 | +21.9 | +44.3 |
| 2020 | +38.0 | +65.7 |
| 2021 | +24.3 | +19.4 |
| 2022 | +53.9 | +53.3 |
| 2023 | +33.4 | +20.6 |
| **2024** | **−8.0** | **−55.5** |
| **2025** | **+1.2** | **+15.6** |
| 2026 | +10.7 | +19.5 |

**8 年 6 正，但最近两年（2024/2025）几乎归零甚至为负**，RECENT 口径 t 掉到 0.43
——正是制度性「TOM 效应在新世纪后衰减」的形态。三条硬伤：
① |t_NW| = 2.36 < 3.0（没到 Harvey 门槛，而且这只做了 14 次正式检验中的一次）；
② RECENT 与 FRONT 符号方向勉强一致但幅度只剩 1/5（t 0.43 = 无信息）；
③ 多口径看，它更像「早年 beta 的结构性残留」而非当期可交易 edge。
参照 `CONSTRAINTS.md` C1 已有裁决「日历/月份/生肖 → 全是大盘贝塔，不是阿尔法」——
本批的 TOM 数字与那条裁决一致，**维持不给例外**（要复活必须走 DECISIONS 变更流程 + 新证据）。

### 2.3 换日历也不换结论：农历初一/十五 = 朔望的另一种记法

lunar_1（初一）diff −7.35bp、lunar_15（十五）+15.48bp、合并 +4.24bp，|t| 全 ≤1.4、p2 ≥0.39。
与天文朔望（moon_new −2.96 / moon_full +10.26）**方向大体同构但更弱**
（因为初一/十五只取「单个交易日」，样本更薄、噪声更大）——
说明「农历版月相效应」并没有独立于天文月相的新东西，而天文月相本身也不显著。

### 2.4 星期效应：只有形状，没有显著性

周一日均 +16.99bp、周二 +11.61、周三 +3.86、周四 −2.90、周五 −2.55（**单调下降**）。
但按「每桶 vs 其余」的差分口径：周一 diff +14.45bp/t=1.36、周五 −9.85bp/t=−1.61，
|t| 全部 <2、p2 最小 0.070。**周内单调是真的，显著性是真的没有。**
8 年 1886 天里「周一涨周五跌」的形状很可能是几个极端周的残留
（与「日历效应 = 大盘 beta 时机成分」的既有裁决一致），不构成可交易信号。

## 4. 为什么这些「全灭」仍然值得记

1. **它把一类反复出现的提问变成一次性销案**：下次有人（包括用户自己）问「天干地支/月相/
   节气有没有用」，答案是一个可复跑的脚本 + 一份带置换检验的表，而不是「我觉得没有」。
2. **它演示了预登记的价值**：如果允许事后挑格，本批可以轻松捞出
   「雨水+立春 5 日 88% 胜率」「周一周五差 26bp/日」两条看着很香、实际 n 不足的
   "发现"。预登记三闸把它们挡在门外。
3. **它补齐了换手/位置之外的第三类"伪因子"清单**：技术指标（#231 全平）、
   位置带（#280 已量化为 beta 层）、日历（本批）——**edge 在结构（簇、深度、条件极端），不在标签。**
