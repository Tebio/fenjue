# A股因子投资实证调研（截至2026年9月）

## 1. 换手率因子（低换手溢价）

| 来源 | 样本区间 | 方法/结论 |
|---|---|---|
| 陈伟、张兵、徐硕正《异质信念、套利限制与低换手率溢价之谜》（《金融经济学研究》2018） | 1995–2017，2698家A股 | Fama-MacBeth+分组：低换手股票预期收益显著更高；加入流动性指标后系数几乎不变，流动性解释力不足10%，异质信念+套利限制解释更强 |
| 复旦金硕论文（上海市金融硕士论文库，2024） | 2006–2018月度数据 | 低换手溢价稳健；组内呈倒U形，高换手组负向效应主导 |
| 学位论文《换手率是好的流动性指标吗》（2021前后） | 2010–2020沪深A股 | 溢价普遍存在、无月份/行业差异；流动性对溢价的解释力度<10%，换手率并非流动性良好代理 |

结论方向一致：A股低换手溢价显著且稳健，但经济含义以"投机泡沫/异质信念"为主，非纯流动性溢价。经典文献另有张峥、刘力《换手率与股票收益：流动性溢价还是投机性泡沫》（被高频引用，具体期刊卷期本次未核实到全文）。

## 2. 波动率/低波异象

| 来源 | 样本区间 | 关键统计量 |
|---|---|---|
| 黄金波、王天娇、曾燕《抽样频率、股价高估与特质波动率异象》（《系统工程理论与实践》2026年第1期） | A股上市公司 | 日频特质波动率异象显著、月频不显著（争论源于抽样频率）；异象由高波动股价格高估+卖空约束（两融失衡）驱动 |
| 齐玉录（《东北财经大学学报》2019） | A股 | Beta异象与特质波动率异象并存；控制特质波动后Beta异象不显著，反之仍显著；低风险异象源于意见分歧下的高估 |
| 东吴证券金工《寻找特质波动率中的纯真信息》（2023.07，高子剑） | 2005.01–2023.06全A | 纯真波动率因子：月度IC −0.046，年化ICIR −1.85，十分组多空年化19.01%，信息比1.72，月胜率70.59%；传统因子IC −0.051但与换手率高度相关、正交化后大幅衰减 |
| 国泰海通金工《如何构建低波策略》（2026.06，郑雅斌/罗蕾） | 2013.01–2026.05 | 红利低波增强组合：年化收益20.6%，年化波动18.7%，信息比1.13，最大回撤34.0%，月胜率64.0%；低换手、低尾盘成交占比个股波动显著低于市场 |

## 3. MAX彩票效应

| 来源 | 样本区间 | 结论 |
|---|---|---|
| 江曙霞、陈青（2013，转引自李捷嵩、刘园2019） | 1997–2011 A股 | 首次证实A股MAX异象；仅存在于趋势性牛熊市，平衡市不明显 |
| 李捷嵩、刘园《投资者关注与最大日收益率异象》（《济南大学学报》2019） | 2011.01–2018.05上证A股 | MAX效应存在；彩票偏好（高MAX+高异质偏度+高异质波动）是主因，投资者关注放大异象，情绪高涨期更显著 |
| 苏刚、刘蕴祺《投资者情绪对MAX效应的影响分析》（《东北财经大学学报》2017） | 中国股票市场 | 组合价差法+Fama-MacBeth：MAX效应显著，主要来自情绪高涨期；对冲组合收益由最高、最低MAX组共同贡献 |
| 董晨昱等（2018，转引） | 中美对比 | 中国MAX异象更多受流动性冲击驱动，区别于美国的彩票偏好解释 |

注：朱菲菲等（2019）"彩票型组合年化收益低超15%"一说仅见于二手文档转引，未核实原文，不采用。开源/华泰等券商对MAX因子的IC统计本次未检索到可靠原文数字。

## 4. 中期动量 vs 短期反转

| 来源 | 结论 |
|---|---|
| 王永宏、赵学军《中国股市"惯性策略"和"反转策略"的实证分析》（《经济研究》2001年第6期） | 中国股市只有反转、无显著动量（被引297次，奠基性结论） |
| 鲁臻、邹恒甫《中国股市的惯性与反转效应研究》（《经济研究》2007年第9期） | 惯性/反转并存但随周期结构变化 |
| 刘博、皮天雷（《金融研究》2007年第8期） | 提供新证据支持短期反转 |
| 谭小芬、林雨菲（《金融评论》2012） | 中期动量不明显、短期与长期反转明显——学术共识 |
| 华泰金工《行业轮动系列（三）》（2020.06） | 截面动量因子在多数行业有选股能力（仅酒类、银行、非银一般）；但2019年以来动量、波动、换手等量价因子表现不佳 |
| 中信建投量化月报（2026.09） | 动量因子近期（2026年8月）阶段性走强——属月度观察而非长期结论 |

最新结论：月度尺度短期反转仍是A股最强量价信号；中期（3–12月）动量长期偏弱但呈周期性，机构化提升后阶段性增强。

## 5. 价值因子（低PE/PB）有效性及失效争议

| 来源 | 关键证据 |
|---|---|
| 华泰金工《价值策略表现分析与结合动量的优化》（2021.08） | 价值因子近年有效性下滑；收益拆解显示"重估收益由正转负"是主因，市场定价逻辑变化；价值+动量合成显著改善收益与回撤 |
| 华泰金工《行业轮动系列（三）》（2020.06） | 2017年起规模因子最先失效，2019年以来估值因子与量价因子表现不佳，成长/盈利因子占优 |
| 国海富兰克林张志强（2019.10） | 2018年以来传统价值因子超额收益远低于历史甚至为负；剔除行业、规模后依然；归因于PB与ROE相关性上升、A股机构化/MSCI纳入后盈利成为定价主导 |
| 《证券市场周刊》（2020.05） | 2019.01–2020.05中证800价值相对成长回撤27%；长期看价值是风险因子而非alpha |

学术期刊层面（经济研究/金融研究）近年的价值因子系统检验本次未检索到高权威新文献，失效讨论主要见于券商金工与基金研究。

## 7. 规模因子（小市值）：壳价值与退市偏差争议

- **壳价值论**：Lee（斯坦福）、屈源育（对外经贸）、沈涛（清华）基于2007–2020年反向并购估算：非上市企业平均支付超30亿元购壳、约占壳公司市值23%；壳价值与IPO监管强度正相关，并显著贡献于中国规模效应（小市值公司超额回报的重要部分实为"重组期权"而非成长溢价）。澎湃专栏有中文改写，正式期刊版本本次未核实。
- **华泰金工（2018.01周报/2020.06）**：2017年市值因子大幅回撤、为大类因子中"最先失效"者。
- **退市端**：袁蓉丽等（《南开管理评论》2026）以2020年退市改革为自然实验：改革显著压低小市值公司超额回报，并倒逼其改善内控与研发。2024年新"国九条"将主板市值退市标准提至5亿元，证券时报报道"保壳手段失效、壳价值归零"已成监管口径。
- **回测偏差提醒**：不剔除退市股/涨跌停约束的回测会系统性高估小市值与反转因子收益（廖理等2018，转引）。
