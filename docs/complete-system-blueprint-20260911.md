## 二、「一年20-30% vs 翻倍」的归因（回答原问题）

- **一年 20-30%**：小市值因子（年化≈25%）+ 高股息全收益（12.6%）+ 打新门票增强（1-4%）——**这是慢而稳的路， alpha 在"身份标签"（市值/股息），不在K线形态**
- **一年翻倍**：主线期重仓龙头（2026-06 AI链级别）或妖股（金健米业8板+121%）——**高方差+幸存者偏差的展示面**，次年大概率均值回归，不可当体系目标

## 三、焚诀完整体系蓝图（Goal）

**目标函数**：长期年化 15-25%、最大回撤 <15%、期望为正且保留右尾——不追求单日胜率（胜率执念=赢次输钱的陷阱）。

```
L0 底仓 50-60%：高股息宇宙买入区挂单（4.5%线买/5%线加）+ 红利再投
    → 年化 8-12% 低波动，兼当打新门票市值
L1 战略因子 20-30%：小市值月度轮动（纪律化调仓，周期仪恐慌/崩盘信号时撤）
    → 主超额来源（需先做存活者偏差修正复核）
L2 战术套利 10-20%：反转族 + 跌停接（复核后）+ 涨停隔夜兑现规则
    → 退潮/妖股期由周期闸门关停（本周连亏 -1.15%/-1.65% 的教训）
L3 事件驱动 0-10%：PEAD 业绩预告策略（B级证据最强的新方向，需建事件库）
黑名单层：D级全禁 + C级不碰（游资跟随是反向指标）
风控层：处置决策树 v1 + 移动止损（宽>窄，1-1.5σ/20%跟踪）+ 单笔风险恒定（海龟 1-2% ATR 定仓）
```

## 四、落地立项清单（按优先级）

## 六、因子补测（自家数据，月度调仓，超额=相对全宇宙等权，91 个月）

| 因子 | 分组 | 月均超额 | 月胜率 | 累计 | 判定 |

| **换手率** | 最高20% | **-0.75%** | 39.6% | **-52.3%** | ❌ 高换手=持续出血（与《金融经济学研究》2018 低换手溢价互证） |
