## 三、管线直接产出的三个新认知

1. **形态族全部过不了 L4**——单笔 edge 0.47-0.73pp、单票年触发 1.4-1.8 次，单独成策略年化贡献 <2%，覆盖不了摩擦。它们的唯一合法位置是**确认层/闸门**，验证了我之前的定性判断，现在有了管线级证据。
2. **大长腿_低位在平淡期是负的（-0.62%）**。regime 维度的意义直接兑现：同一信号在恐慌期 +2.39%、平淡期亏钱。之后的形态用法必须带 regime 闸门。
3. **TD9 神奇九转在衰减**：2019-22 还有 +0.87%，2023-26 只剩 +0.05%。名气最大的指标死得最快——可能正是用的人太多。这支持"热度越高死越快"的因子半衰期假设。

## 四、避雷针_低位的恐慌期放大（+2.07%）值得记

恐慌期+低位+长上影 = 最强组合。机制假说（L1 候选）：恐慌期主力借恐慌试盘，上影是主动探测卖压的痕迹，不是被套。待组合层（S3）验证它与反转族叠加是否产生超额。

## 六、S1.5 方法论对齐（2026-09-11 深夜，对照成熟开源项目后当场迭代）

用户质问"这种方法真的正确吗，人家成熟 GitHub 项目怎么做的"。对照 alphalens / 微软 qlib / Harvey-Liu / Bailey-López de Prado 后，管线当场补三样：

| 补进的成熟实践 | 来源 | 实现 |
|---|---|---|
| 多持有期衰减曲线 T+1/3/5/10/20 | alphalens/qlib IC 惯例 | `衰减曲线` 字段，同一批事件五期复算 |
| Newey-West HAC t 值（重叠窗口修正） | 学术标准 | `nw_t()`，lag=持有期 |
| 多重检验门槛 t_NW≥3.0 | Harvey & Liu 2015 | 每格自动标"过Harvey门槛" |

仍未对齐的欠账：Deflated Sharpe（策略层，等组合层 S3 再上）、PIT 宇宙/幸存者偏差（退市股不在 big_kcache，全仓库口径一致的老欠账）、Purged CV（非 ML 暂不需要）。

### 衰减曲线改写了结论

- **低位避雷针/低位大长腿不是 T+5 信号，是 T+20 信号**：收益随持有期单调放大（避雷针低位 T+1 +0.10% → T+20 **+3.07%**，胜率 54.3%，t_NW=32.8 全期过 Harvey）。这是真性均值回归，不是短炒噪音。→ 用法从"确认层"升级为"反转族的 20 日持仓确认指标"。
- **TD9 买入结构 T+1 是负的（-0.04%，t_NW=-9.1）**：信号出现次日买入第一天必亏，edge 从 T+3 才开始。"九转现身即抄底"在数据上错误——它标记的是底部区域而非底部当天。
- **高位避雷针是教科书出货形态**：T+1 +0.28%（拉高）→ T+20 -0.29%（派发完成），递减曲线=主力倒货的时间签名。
- NW 修正后真信号 t 值从 25~35 降到 16~33 仍远过 Harvey 3.0——edge 不是 t 值膨胀假象。

## 七、S1.6 终审：日历时间组合法 + DSR + 位置匹配对照（同晚第二刀）

用户要求继续找方法论差距。补三件成熟标准里最狠的：

| 补进 | 来源 | 治什么 |
|---|---|---|
| 日历时间组合法（事件按日聚合，减当日全宇宙均值） | Fama-French 标准 | 事件在恐慌日扎堆 → 横截面相关把同一天 100 只票当 100 个独立样本 |
| Deflated Sharpe（trials=25 修正） | Bailey & López de Prado 2014 | 我已试过 25+ 策略的选择偏差 |
| 幸存者偏差量化 | baostock query_all_stock | 2019 主板 2818 只在交易 → 191 只已退市（6.8%）不在库 |

### 终审判决（残酷但诚实）

1. **日历时间口径下形态族全灭**：作为"每天买一篮子信号票"的无闸门独立策略——TD9 日超额 -0.122%（DSR=0）、大长腿低位 -0.074%（DSR=0.003）、避雷针低位 +0.052%（DSR=0.105，远不达 0.95）。**事件研究里的 +1.0% 有一大块是"抄底那天全市场都在反弹"的 beta，不是形态的 alpha。**
2. **regime 闸门也救不了日历时间口径**：恐慌期专属篮子日超额 -0.074%（DSR=0.005）——恐慌日里买什么都在弹，避雷针票不比其他票弹得多。
3. **但位置匹配对照给出终审反转**：对照组改为"同一只票、同在 MA60 下方的随机日"（剥离位置因子）后——
   - T+5：信号 +1.00% vs 对照 +0.33% → **形态边际贡献 +0.67pp**
   - T+20：信号 +3.07% vs 对照 +1.52% → **形态边际贡献 +1.55pp**
   - 形态不是位置的代理变量，它携带独立信息（试盘痕迹），且边际贡献随持有期翻倍。
4. **幸存者偏差方向性警告**：191 只退市股生前最后一年大概率长期低于 MA60 → 它们会密集落入"低位"信号组而被整体排除 → 低位系信号的实测 edge **系统性偏高**，真实值打折。此欠账只有补拉退市股 K 线才能销。

### 修正后的最终用法（写死）

**低位避雷针 ≠ 独立策略（日历时间口径已证伪），= 反转族/低吸框架内的形态确认指标，持仓 20 日维度。** 其 edge 构成 = 位置均值回归（约一半）+ 形态试盘信息（约一半）。对单票的决策含义：看到低位避雷针，该问的不是"这形态灵不灵"，而是"我现有的位置型买入框架要不要给它加分"。
