# R0 机制模型（未碰数据版本，2026-10-19）

## 为什么起这条线

已死的三条线（打板、半路板、深档低位）结构上犯同一个错：**在价格已经异动的当天，去和抢的人排队**。
排队 = 逆向选择：能成交的时候，通常是对面知道得比你多。

唯一活着的崩盘抄底（n=28，DSR 过不了）结构上是对的：**次日开盘市价单，无排队，成交与否对称**。
所以新线必须继承这个结构优势。

## 候选：首板涨停 → 缩量回踩不破 → 二次启动

**这不是打板线的变体，是它的反面。** 打板买在涨停价（排队、逆选）；这条线买在回踩日（无排队、自己挑价格）。

### 因果链（每步必须可证伪）

1. 首板涨停 = 有资金愿意以 +10% 吃货，且封住了 → 存在明确的做多意图（不需要猜是谁）
2. 首板次日/第三日，**结构性卖压必然出现**：当天在涨停前后买入的人已有 +10% 浮盈，兑现动机天然存在
3. 卖压强弱可以从**回踩日换手率**读出来：
   - 回踩日显著缩量（换手 ÷ 首板日换手 < 0.6）→ 获利盘没跑，筹码锁定
   - 回踩日放量（比值 > 1.0）→ 获利盘在派发，接盘的是散户
4. 若回踩日**不破首板日收盘价**，说明买盘承接住了这批卖压
5. 3 与 4 同时成立 → 二次启动概率高于基线

### 谁在对面卖 / 我为什么买
- **对面**：首板的获利盘。他们卖是因为 +10% 够了，不是因为他们知道坏消息。
- **我**：买的不是涨停，是「卖压测试通过」这个信息。
- **对手方动机不对称**：他的是止盈（无信息），我的是接信息（有信号）。这是这条线的 edge 来源。

### 队列风险 = 零（这是关键）
买入价 = 回踩日收盘价或次日开盘价，**不是涨停价**。挂市价单即可成交，不存在「排不上队」。
→ 与打板线的根本区别，也是打板线三次口径错误的根源（一字板买不到）在这条线上不存在。

### 我在哪个环节被筛掉
回踩日直接大跌/跌停（-7% 以上），我买在下跌中途 → **这是唯一的主要亏损来源**，必须在机制上假设它会发生，不能靠剔除样本处理。

### 最坏情况
假二波：买入后继续阴跌，T+5 -15%+。

### 与崩盘抄底的关系
共享「无排队」结构优势，但触发条件不同（崩盘抄底要全市场恐慌，这条线要个股锁筹）。
若两条线同时触发同一只票 → 置信度更高；若互斥 → 分散。

## 关键调节变量（禁止用边际分布代入）

| 变量 | 为什么必须条件化 |
|---|---|
| 首板日换手率 | 区分强封/弱封；弱封的"缩量回踩"可能只是没人要 |
| 缩量比 = 回踩日换手 / 首板日换手 | 核心自变量 |
| 位置（是否在 MA60 上方） | 低位首板与高位首板是两种东西 |
| 流通市值 | 小盘股缩量可能是没流动性，不是锁筹 |
| 当日全市场涨停家数 | 情绪温度，决定二波的普遍性 |

## 预登记 trial 网格（写死，只跑这一组，不许事后加）

- 首板定义：主板，涨停且封住，连板数 = 1
- 回踩日：T+1 或 T+2（两选一，各算一次）
- 不破判定：回踩日收盘 ≥ 首板日收盘 × 0.98
- 缩量比档：<0.6 / 0.6-1.0 / >1.0（三档）
- 持有期：T+3 / T+5（两档）
- **合计 trials = 2 × 3 × 2 = 12**（加基线 1 = 13）

**这 13 个就是全部。若 13 个全过不了，判死，不再扩网格。**

## 证伪条件（写死，不许事后改）

1. T+5 平均收益 ≤ 0.5%（不足 2.5× 成本 0.2%）→ **判死**
2. DSR（用实测 Var(SR_trials)，N=13）< 0.95 → **最多进影子账，不许上生产**
3. 信号数 < 30 → **样本不足，不许下任何结论**（打板线已犯过：28 个事件就敢报年化）
4. 缩量比三档**不单调** → 机制不成立，即使某档赚钱也不采信（可能是噪声）
