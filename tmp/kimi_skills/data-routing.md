# data-routing —— 取数路由的唯一指针

本仓库所有 skill 的取数**只写一行指针指到这里**，不准各自复述规则。复述就是新副本，
半年后必然漂开（2026-09-16 实测：同一个 skill 的 `SKILL.md` 与 `style.md` 一个禁 emoji
一个规定 `⚠️`，两份都还在用）。

## 分工：执行层在哪看第 1 节，出数纪律在这里

| 层 | 本发行版怎么办 |
|---|---|
| **怎么取**（端点、降级链、覆盖上限、成本、已知坑） | **两条路**：付费源（ifind / Wind / S&P CapIQ）走仓内 `finance-data/` skill（用户自有网关与 key，未配置自动降级）；免费源与各 skill 自带直连脚本；兜底公开披露原文（SEC EDGAR / 交易所披露 / 公司 IR）或你所在机构的数据终端 |
| **出不出数、怎么标**（覆盖闸、锚定、口径标签、展示规范） | **本 skill 第 2 节** —— 与取数通道无关，换谁取数都成立 |

第 2 节这些判据是从多源交叉实测里长出来的：它们约束的不是「从哪拿数」，而是「拿到之后
什么情况下不许出、出了必须标什么」。**换一套数据源，这些闸一条都不能松。**

## 1. 怎么取：执行层在哪，这八条与通道无关

1. **不换算、不改数**：数值保持数据源原样，量纲与币种随数带出，换算由上层显式做
2. **拿不到就是 null**：不猜不编；行项对不齐置 null 并说明；降级链走完仍没有就如实返回
3. **先定路由再调用**：从主源开始，**真实失败**（报错 / 空 / 不覆盖）才逐级降，不预先跳级
4. **口径显式**：输出带报告期口径（as-reported / ytd / annual / quarter），单季与累计分开；
   期次先对齐官方披露日历——**未披露 ≠ 数据缺失**
5. **价格序列必须带复权口径**（forward / backward / none）：源不支持或默认不复权的要标实际
   口径，不许混用、不许把不复权当复权出
6. **覆盖范围即降级条件**：需求超出某层覆盖上限（要 10 年而它只有 3 年）＝合法的降级触发，
   与「失败」同等对待
7. **兜底可用公开披露原文**（SEC filing / 交易所公告 / 公司 IR），但必须标来源与口径；
   仍拿不到就如实说，不编
8. **引用新闻必带三要素**：发布时间、URL、媒体名，缺一不引用
9. **akshare 能不用就不用**（2026-09-18 起，全集适用）。它不是"免费源"的同义词，
   而是**别人端点的一层包装**——包装层会独立于上游失效，且失效时不报错：
   2026-09-18 实测 `macro_china_cpi_monthly` / `macro_china_ppi_yearly` /
   `macro_china_pmi_yearly` / `macro_usa_non_farm` 四个接口全部停在 **2025-08**，
   落后整整一年，却照常返回 200 与一张完整的表。**没有异常、没有空值，只是数据是旧的**
   ——这类失效连闸带校验一起放行，读者看到的是一个"看起来对"的去年数字。
   （同一批 `macro_china_money_supply` 是活的，可见是逐接口的源失效，不是网络问题。）
   它还把 pandas + numpy（67 MB）绑进依赖，而多数调用点只要几个标量。
   **正确做法：往上游走一层**，从 akshare 本机源码里取出它调的那个端点（reportName /
   列代码 / 官方序列号都在源码的 rename 表里，是权威不是推断），然后直连。
   已完成的置换：`morning-briefing/cn_macro.py`（国债曲线 / 回购 / 两融 / 南向）、
   `morning-briefing/macro_monthly.py`（CPI / PPI / PMI / M2 / 社融 / 非农）。

### 1b. 月频宏观：finance-data 不覆盖，走官方端点

**已核实的缺口（2026-09-18）**：仓内 `finance-data/` skill（ifind / Wind / S&P）
`routing.json` 只有公司层 14 类 scenario（`{cn,hk,us}.{quote,kline,income,bs,cf,
consensus,announcements,news,events,segments,financials,filings,transcripts,peers}`），
**没有任何宏观路由**。别去那里找 CPI/PMI/非农——不是没配好，是不在覆盖范围内。

在付费源补上宏观之前，月频宏观按下表直连（均为官方或官方转发层，零 akshare）：

| 指标 | 源 | 端点 |
|---|---|---|
| CPI / PPI / PMI / M2·M1 | 东财数据中心（转发层） | `datacenter-web.eastmoney.com/api/data/v1/get` + `RPT_ECONOMY_{CPI,PPI,PMI,CURRENCY_SUPPLY}` |
| 社融增量 | **商务部数据中心**（官方） | `data.mofcom.gov.cn/datamofcom/front/gnmy/shrzgmQuery`（POST 无参；字段 `date` / `tiosfs`） |
| 美国非农 | **美国劳工统计局**（官方，免 key） | `api.bls.gov/publicAPI/v1/timeseries/data/CES0000000001`（季调，千人） |

已知滞后：商务部社融增量**比其余五项晚约四个月**（2026-09 实测最新只到 2026-04）。
这是源的发布节奏，不是取数失败——按缺数处理并写明原因，**不用上一期顶替**
（月频顶替一次，下一期的同比就全错）。

## 2. 出不出数：取数层之上的闸

取数层负责「取到什么」，这一层负责「**能不能拿出去见人**」。全部宁缺毋假。

1. **家数 < 3 不出一致预期**。实证：某中概 ADR 某档只有 1 家给正值，孤证能算出一个漂亮的正 PE，
   而市场一致是亏的；NIO 同型。1 家 = 孤证假阳性，不是数据。
2. **FY1 EPS ≤ 0 不出正 PE**。要么出负值并标注，要么滚到第一个正年度**并把年份打在图上**
   （美团 FY2026 一致亏损 / FY2027 转正——不标年份读者会当成当年）。
3. **锚只认 `period_end_date`**（第一个 ≥ today 的财年末），**不认年份标签**。
   跨源比对只在同一 `period_end` 之间做；标签年份相同 ≠ 同锚。
4. **标财年不标日历年**：写 `Fwd PE FY27`，不写 `2026E`。NVDA `period_end 2027-01-31` → FY27、
   AAPL `2026-09-30` → FY26、BABA `2027-03-31` → FY27。
5. **三口径分开不共用标签**：NTM（w×FY1+(1−w)×FY2 加权）/ 当年 est（FY1）/ FY+1。
6. **EPS 币种判不出就拒算 PE**，绝不默认与股价同币种。港股共识 EPS 跟**记账本位币**走
   （腾讯/阿里 = CNY、汇丰/友邦 = USD、长和 = HKD），原始单位是仙/分要 /100——
   2026-09-03 修复前恒钉 HKD，汇丰差 7.8 倍、友邦 99.7x。
7. **价格与 EPS 同源同刻**，否则时差/汇率差会伪装成源间差。
8. **口径 non-GAAP 优先**（CapIQ `caliber='adj'`），拿不到再退 GAAP；港股/A股本地共识是
   报表口径 —— 同一张表混口径＝隐形失真，footer 必须写清用的是哪一档。
9. **倍数后面带 `x`**：`28.4x`，不是 `28.4`（裸数字分不清倍数还是价）。
10. **复权口径靠对账认定，不靠读声明**。加新价格源前必须与一个已知前复权源逐日对账，
    中位差 < 0.5% 才算数——声明与实际**两个方向都错过**（gtimg 港股自称 qfq 实为不复权，
    00700 拆股跳空 4.42 倍；datasource:yahoo 自标 unadjusted 实为美股前复权）。

### 数据通道状态不外曝（用户可见输出）

出数纪律管「拿什么见人」，这条管「通道本身说不说」：用户可见输出（对话、进度汇报、断点回复、报告正文/附录）**禁止披露数据通道的配置与运行状态**——网关/key/token 是否配置、UA 是否设置、走了付费层还是免费层、降级路由细节一律不写。对用户只说**实际用了哪些来源**（来源标注与 tier 承担透明度）；通道缺口写成数据缺口（「缺少 X 数据/覆盖」），不写通道为什么缺、怎么绕。确需用户动手配置时只提一句「需要配置 X」，不展开后端细节。

### yfinance 到底能不能用（这条被改过两次，两次的错法不同）

1. 最早的写法「估值字段中位偏差 17–24%、最差 −40%，只配兜底」—— 数字对，**归因错**。
2. 09-16 按 09-03 的逐位核对改成「锚是 FY+1，标清就能用」—— **也错**：那批样本
   （AAPL 一类）恰好都落在 FY+1，被推广成了全体。

**真实形态：锚因股而异，且随各公司财报节奏滚动**（morning-brief 2026-09-11 三只对照
S&P，2026-09-16 复现）：

| ticker | forwardEps | 实际等于 | 当前财年口径 PE | yfinance 口径 PE |
|---|---|---|---|---|
| NVDA | 15.57 | FY2028（**FY+2**） | 23.5x | 14.0x（差 40%） |
| SNDK | 264.72 | FY2028（**FY+2**） | 7.9x | 6.4x |
| AAPL | 9.57 | FY2027（FY+1） | 34.1x | 34.1x（一致） |

所以：

- ❌ **不要假定锚在哪一年**（不是 FY1，也不是固定 FY+1）
- ✅ 要用就先按 `period_end_date` 把它对回某个具体财年（与 S&P/Wind 的同锚档比），
  对不上就别用；写进报告的每个 PE 都必须带财年标签
- ❌ A股 `forwardPE` 回 USD 口径（PE 放大约 6 倍）、港股常空 —— 与锚无关，任何情况下不用
- ❌ `trailingPE` 不作前瞻依据

教训本身也是判据：**样本恰好一致 ≠ 规律**。改这一节必须附反例检查，不是找一批对得上的就收工。

主源仍是 A/H **Wind**、美股 **S&P CapIQ Normalized FY1**、中概 ADR **Gildata**（按每 ADS 报，
免存托比率那一整类坑；与 S&P 互证差 0.5%）。⚠️ Wind 的 NL 一致预期**问句必须钉死年度**，
不钉会在 FY1/FY2 之间掷硬币，而返回 CSV 的「预测年度」列恒为空、事后无法校验。

### 两条最常被漏掉的

- **PE band / 估值带**（PE-TTM 日频序列 + 分位）：实现自备，口径是死的 —— 序列 < 60 点
  报错不硬画、亏损期（EPS ≤ 0）断点不连线、EPS 与价格必须同源同刻。
- **分部默认要拆**：Sankey / 收入结构最左列默认追求业务线拆分，逐级穷尽才许降级
  （美股 filing 的分部 R-file → A股主营构成（半年频）→ 港股业绩公告 PDF 的分部表），
  都拿不到就画到「总营收」为止 —— **不许编分部**。

## 3b. 双端降级纪律（Work 桌面端 / web 托管端）

同一份 skill 代码两端都跑。**降级是运行时探测的结果，不是代码写死的**——
这一条是为了同时保住两件事：Work 端**一点不缩水**，web 端**缺件时不硬崩也不装作没事**。

### 铁律一：Work 端探到什么就用什么，**不因为另一端缺就两端都不用**

🚫 反面写法（把两端拉齐到低的那一端）：

```python
SKIP_PDF = True          # web 沙箱没有 Chrome，干脆都不出
```

✅ 正面写法（各自跑满自己的上限）：

```python
caps = json.loads(subprocess.run(
    [sys.executable, "<finance-data>/scripts/env_probe.py", "--caps"],
    capture_output=True, text=True).stdout)
if caps["pdf_export"]:
    export_pdf(html, pdf)                 # Work 端照常出 PDF
else:
    notes.append("PDF 出口：本环境缺渲染引擎，仅交付 HTML")
```

能力查询走 `finance-data/scripts/env_probe.py --caps`（不联网、不装包，一次约 50ms），
返回 `pdf_export` / `screenshot` / `formula_recalc` / `slides_export` / `node` / `curl` /
`native_preview` / `cjk_font` 八个布尔。判据一律是「**这台机器现在有没有**」，
不是「web 端一般没有」。

### 铁律二：三类东西，处置完全不同

| 类 | 例子 | 缺件时怎么办 |
|---|---|---|
| **可降级**（出口层） | PDF 导出、版面截图目检、中文出图、xlsx 公式缓存值、程序化导出 pptx | 降级交付 + **在产物里写明缺什么、因此少了什么** |
| **换载体**（同源不同出口） | slides：**两端同样是 pptd**，只有导出这一步按环境定 | 交到 pptd 为止，不改 deck 源、不另找画法 |
| 🚫 **绝不降级**（口径层） | 本页第 2 节全部：家数<3 不出数、PE 必带财年、锚只认 period_end、拿不到就留空 | **两端逐字一样**。这是纪律不是能力，跟环境无关 |

第三类是分界线：**缺件可以少交一样东西，但不能让同一个数在两端不一样**。
渲染差异会报错（显式）；口径差异两边都出数、数却不同（隐式）——后者才是真正难查的。

### 铁律三：降级必须留痕，不许静默

缺件时在交付说明/产物尾部固定写一行：**缺什么 → 因此少了什么**。
`morning-briefing` 是现成写法（缺 Chrome 时写明"PDF 出口缺渲染引擎，仅交付 HTML"）。
🚫 只交 HTML 却不说，等于漏交；🚫 缺字体照样出方框图，等于交废件。
